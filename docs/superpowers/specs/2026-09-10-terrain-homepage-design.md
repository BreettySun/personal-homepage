# 个人主页「地形志」设计文档

日期：2026-09-10
状态：待用户审阅

## 1. 目标与定位

- 站主是一名前端程序员，网名 Scream（取自张悬的歌）。同时写散文，文章以地貌和城市命名（平原、丘陵、河流、湖泊、青岛、秦皇岛……），气质克制、安静，反复出现天气、季节、火车、北京通勤等意象。
- 主页是纯个人表达，面向朋友和路人，不是求职作品集。
- 视觉目标："充满视觉效果"，但效果服务于内容：首页负责惊艳（3D + 动效），内容页负责好看且好读（纸感排版）。
- 全站要有一点程序员的味道，但藏在细节里，不破坏纸与墨的气质。

## 2. 核心概念：地形志

- **整站隐喻是一张地图。** 首页是一片俯瞰的 3D 地形，文章、项目、关于是地形上的三处地点。
- **天气是活的。** 首页地形叠加真实天气与季节（雨、雪、落叶、晴），数据来自北京实时天气，也可手动拨动。
- **程序员味道的三种融法**（已确认全要）：
  1. 等宽字体做"注释"：日期、城市、天气、字数等元数据用等宽字体，写成 `// 2025-11-30 · 北京 · 阴 · 1,203 字` 的形式。
  2. 地形是数据生成的：首页地形由噪声函数实时生成，右下角有 shader 调试面板风格的参数面板（种子、雨量、季节）。
  3. 终端彩蛋：全站按 `~` 呼出终端，支持 `ls`、`cat`、`whoami` 等命令。

## 3. 视觉系统

### 3.1 主题

两套主题，默认跟随系统 `prefers-color-scheme`，右上角一个小开关手动切换，选择存 localStorage。

| 角色 | 浅色「宣纸」 | 深色「雨夜」 |
|---|---|---|
| 背景 | `#F3EEE4` | `#151A20` |
| 次级背景 / 分割 | `#E4DCCB` | `#232B34` |
| 辅色（灰蓝） | `#5B6B7A` | `#7C8A99` / `#8A97A6` |
| 正文 | `#2B2A28` | `#E6E0D4` |
| 强调（极少使用） | 朱砂 `#B5453C` | 窗灯 `#D9A441` |

全部以 CSS 变量定义在根元素上，组件只用变量。

### 3.2 字体

- 正文：思源宋体 Noto Serif SC，字号 17px 左右，行高约 2.0，阅读宽度约 640px。
- 注释 / 元数据 / 终端：JetBrains Mono，11 到 13px。
- 中文字体在构建时按 `content/` 中实际出现的字子集化，目标体积几百 KB 以内。系统回退栏：Songti SC、STSong、SimSun。

### 3.3 动效原则

- 首页：3D 与动效负责氛围。
- 内容页：只保留必要过渡。段落随滚动逐段淡入，页面切换用 vue-router 过渡做淡入淡出。
- 尊重 `prefers-reduced-motion`：关闭 3D 场景与段落动效。

## 4. 页面

### 4.1 首页 · 地图（构图 C「图例」，单屏）

- 全屏 3D 地形是绝对主角。地形是噪声生成的网格，以等高线式的线框呈现（不做实心低多边形），颜色随主题：浅色主题下是灰蓝雾气中的浅色地形，深色主题下是墨蓝夜色中的暗地形。
- 左下角一张"图例"卡片，包含：`LEGEND · 图例` 等宽小标、名字 Scream、三条入口（● 文章 `essays/`、▲ 项目 `projects/`、□ 关于 `whoami`）、底部一行等宽注释（日期、城市、天气、种子）。参数面板合并进这张卡片，可展开。
- 地形上三处标记点对应三个入口，鼠标靠近亮起并轻微抬高，点击进入对应页面。
- **开场动画**：首次进入时地形从雾里浮现，"Scream" 以大字出现在屏幕中央停约一秒，然后缩小滑入左下角图例卡片。同一会话内再次回到首页不重播。
- **滚轮**：不翻页，控制镜头高度（推近拉远），有上下限。首页只有这一屏，没有更多内容。
- 鼠标移动带来轻微视角漂移（视差）。
- 天气效果：雨丝、雪花、落叶三种粒子，晴天无粒子仅改变光照和雾色。

### 4.2 文章列表 · 书的目录（版式 A）

- 页头等宽注释：`$ ls ~/essays  # N files`。
- 大标题"目 录"。
- 按年份分组，年份用等宽注释 `// 2025`。
- 一行一篇：标题在左（宋体、约 20px、字距略宽），城市与天气在右（等宽），中间用引导点连接。悬停时该行引导点变为强调色。

### 4.3 文章正文页

- 单栏，阅读宽度约 640px。
- 头部一行等宽注释：日期、城市、天气、字数、阅读时长。
- 大标题（约 44px），导语为文章第一句，灰蓝色。
- 段落随滚动逐段淡入，未读到的段落低透明度。
- 右侧竖排"海拔"阅读进度，代替进度条。
- 正文内不再有任何代码感。
- 页尾：上一篇 / 下一篇。

### 4.4 项目页

- 沿用目录排版，页头 `$ ls -la ~/projects`。
- 一个项目一行：左侧名字和一句话，右侧等宽字显示技术栈与年份。
- 点击一行原地展开：说明、截图（可选）、GitHub 链接、线上链接。不做独立详情页。

### 4.5 关于页

- 页头 `$ whoami`。
- 散文式自我介绍，用站主自己的话写；名字由来单独一小段。
- 结尾一排等宽字社交链接 `github · mail · …`，不用图标。
- 一屏以内，留白多。

### 4.6 终端彩蛋

- 全站按 `~` 呼出，从底部升起半透明雨夜色面板，约 40% 视口高度；再按 `~` 或 Esc 收起。
- 命令：`help`、`ls [essays|projects]`、`cat <文章名>`（跳转到文章）、`cd <essays|projects|about|~>`、`whoami`、`weather`、`seed <hex>`、`theme <dark|light>`、`clear`，以及一两个玩笑命令（如 `sudo` 回复"你没有权限，去找老王"）。
- 支持上下键翻历史、Tab 补全文章名。
- 输入框获得焦点时全站其他快捷键不生效。

## 5. 数据

### 5.1 内容源

所有内容是仓库内的 Markdown 文件，新文件放入即自动出现。

```
content/
├─ essays/<slug>.md     头部：title, date, city, weather, (summary 可选)
├─ projects/<slug>.md   头部：name, stack[], year, github, url, (cover 可选)
└─ about.md
```

内容管线在构建时用 `import.meta.glob` 读取全部文件，用 gray-matter 解析头部，Markdown 转 HTML，统计字数与阅读时长，产出一份纯数据列表。页面与终端都只从这份数据读。

### 5.2 天气

- 数据源：Open-Meteo 公开接口，无需 key，浏览器直接请求，固定查询北京。
- 映射：天气代码映射为 `clear | cloudy | rain | snow` 四种状态；季节按日期计算（春夏秋冬）。
- 失败降级：请求失败或超时时按季节给默认天气，页面永远可显示。
- 手动覆盖：参数面板与终端命令可覆盖天气、季节、种子，覆盖值存 localStorage，图例卡片上标注"手动"。

## 6. 技术方案

**路线：Vite + Vue 3 + vite-ssg，3D 与动效手写。**

- 3D：Three.js 直接在一个 Vue 组件内使用，地形高度与颜色由自定义 shader（噪声）生成，天气粒子也是 shader。
- 动效：GSAP（开场动画、段落淡入），vue-router 过渡做页面切换。
- 预渲染：vite-ssg 将每个路由（含每篇文章）输出为静态 HTML，GitHub Pages 直接托管，文章链接可分享，无需 SPA 的 404 跳转 hack。
- 未选 Nuxt（约定过多，对五页站偏重，自定义 shader 在 TresJS 里多一层绕）与 VitePress（文档站骨架，首页 3D 需掀掉默认主题）。

### 6.1 目录

```
personal-homepage/
├─ content/                  内容（见 5.1）
├─ src/
│  ├─ main.ts                vite-ssg 入口，注册路由
│  ├─ App.vue                主题变量、全局导航、终端挂载点
│  ├─ router.ts              / 、/essays 、/essays/:slug 、/projects 、/about
│  ├─ content/               内容管线：读 md、解析头部、生成列表与路由
│  ├─ terrain/               Three.js 场景：地形网格、噪声 shader、天气粒子、相机
│  ├─ weather/               Open-Meteo 请求、映射、季节计算、手动覆盖
│  ├─ terminal/              终端组件 + 命令注册表，一个命令一个文件
│  ├─ theme/                 明暗主题、CSS 变量、系统偏好、手动切换
│  ├─ pages/                 Home / EssayList / Essay / ProjectList / About
│  └─ components/            Legend 图例卡、ParamPanel、Altitude 进度、Meta 注释行
├─ public/
├─ scripts/subset-fonts.mjs  构建前子集化宋体
└─ .github/workflows/deploy.yml
```

### 6.2 模块边界

- **内容管线**：输入是 `content/` 下的文件，输出是一份纯数据（标题、日期、城市、天气、HTML 正文、字数、阅读时长、slug）。不依赖任何 UI。
- **地形模块**：对外只暴露一个组件与三个响应式参数：天气状态、季节、种子。参数面板、终端、天气模块都只写这三个值，不接触 Three.js 内部。
- **天气模块**：输出天气状态与季节，带降级与手动覆盖。
- **终端**：命令注册表，每个命令一个小文件，接口为 `(args, context) => 输出行[]`，context 提供内容数据、路由跳转、主题与地形参数的写入。加命令不改终端本身。
- **主题**：只负责根元素上的 CSS 变量与 `data-theme` 属性。

### 6.3 性能与降级

- 宋体构建时子集化。
- 3D 场景只在首页挂载，离开首页即销毁并释放 WebGL 资源。
- `prefers-reduced-motion` 或 WebGL 不可用时，用一张静态地形图代替，图例与导航照常工作。
- 移动端：降低网格密度与粒子数，禁用鼠标视差；终端彩蛋在无物理键盘的设备上不提供入口。

### 6.4 错误处理

- 天气请求失败：按季节默认值，图例注释显示"默认"。
- Markdown 头部缺字段：构建时报错并指出文件名，不允许静默通过。
- 终端未知命令：回复 `command not found`，并提示 `help`。
- 地形 shader 编译失败：回退到静态地形图。

### 6.5 测试

- Vitest 单测：内容管线（头部解析、字数统计、排序分组）、天气映射与季节计算、终端命令解析与补全。
- Playwright：首页与文章页能渲染、终端能呼出与收起、主题切换生效；以截图做回归。
- 3D 与动效不写单测，靠手动验收。

### 6.6 部署

- GitHub Actions：push 到 main 时安装依赖、子集化字体、执行 `vite-ssg build`，产物发布到 GitHub Pages。
- 若仓库名不是 `<用户名>.github.io`，Vite `base` 设为 `/<仓库名>/`。
- `.superpowers/` 加入 `.gitignore`。

## 7. 范围外（本期不做）
